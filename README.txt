# Spring Contact App

## Features
- Add Contact
- View Contacts
- Update Contact
- Delete Contact

## Tech Stack
- Spring Boot
- MySQL
- Thymeleaf
- Maven

## How to Run
1. Configure MySQL in application.properties
2. Run the Spring Boot app
3. Open browser: http://localhost:8080

Import this folder in Eclipse as Existing Maven Project.
Run ContactAppApplication.java
Open http://localhost:8088
H2 Console: http://localhost:8088/h2-console
JDBC URL: jdbc:h2:mem:contactdb
